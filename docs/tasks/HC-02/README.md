# HC-02 — Dominio deportivo

**Objetivo:** formalizar el modelo de negocio deportivo de TRAKIA antes de implementar sus funcionalidades.

**Estado del bloque:** en curso.

**Alcance inicial:** catálogo de ejercicios, planificación, ejecución de sesiones, actividades voluntarias y mediciones corporales. La especificación conceptual se mantiene separada de contratos externos y persistencia, de acuerdo con [ADR-015](../../decisions/ADR-015-arquitectura-modular.md).
