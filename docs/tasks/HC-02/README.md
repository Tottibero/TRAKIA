# HC-02 — Dominio deportivo

**Objetivo:** formalizar el modelo de negocio deportivo de TRAKIA antes de implementar sus funcionalidades.

**Estado del bloque:** tareas completadas; pendiente de PR, CI e integración autorizada en `main`.
